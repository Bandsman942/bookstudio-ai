# BOOKSTUDIO AI — v0.28.0-alpha (candidate NON fusionnée / NON déployée)

## Contenu

Issues **#151** (correctif UI vidéo des menus de livres) et **#152** (BS-008b / BS-004g, comparaison de deux éditions). Correction de la modale « Modifier les propriétés… » observée par vidéo : les dialogues **Renommer / Propriétés / Statut / Archiver** sont rendus via `createPortal(...,document.body)` au-dessus des cartes transformées. Overlay stable dès la première image, safe areas mobiles, scroll et focus conservés.

Comparaison serveur privée des dernières **empreintes de révisions enregistrées** (titres, positions, contenu égal ou différent) entre deux éditions d'un même ouvrage, basée sur rapprochements conservateurs : correspondances uniques par emplacement+texte+titre, hash de contenu identique, ou titre identique. Résultats : inchangés, chapitres modifiés, renommés, déplacés, ajoutés et absents. **Aucun texte, HTML, JSON de manuscrit ou hash brut dans la réponse de comparaison ; aucune édition n'est modifiée.** Limite 350 chapitres actifs/édition ; les cas ambigus ne sont pas artificiellement associés.

Tests unitaires, garde statique UI contre régression du portail, E2E HTTP réels multi-tenant/copies/modifications/ajouts et contrôles UX responsive FR/EN. Aucune migration SQL ni nouvelle variable.

## Risques

- **Candidat non livré** : CI finale, documentation prépublication et E2E propriétaire `v0.28.0-alpha BON` requis avant snapshot Neon, fusion main et Vercel production.
- Le rapprochement n'est **pas une preuve de lignée** : un chapitre entièrement réécrit et renommé peut apparaître comme absent+ajouté. Une correspondance de titres unique détecte une modification de contenu, mais pas les différences mot à mot. Les anciens snapshots restent inchangés.
- Une comparaison supérieure à **350 chapitres actifs/édition** nécessite un traitement asynchrone ultérieur. Aucune prose ni hash de révision ne doit être loguée ou exposée.
- Fenêtres accessibles depuis clavier/mobile et cartes survolées : vérifier focus, Echap, clic extérieur, scroll et backdrop sur 320/375/768/1364px ; certaines modales des autres modules peuvent suivre d'autres circuits et nécessiter des tests distincts.
- Scanner ClamAV réel non installé, flags antivirus OFF et P0 #104/#126/#131/#133 ouvertes. Ne pas prétendre que les manuscrits de production sont analysés.
