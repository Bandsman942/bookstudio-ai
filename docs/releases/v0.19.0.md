# BookStudio AI v0.19.0-alpha — candidate (NON FUSIONNÉE, NON DÉPLOYÉE)

## Contenu

### #127 — CRUD chapitre, navigation et commandes contextuelles

- Le chapitre peut être **retiré de la navigation active** avec confirmation ; suppression réversible par champ `deletedAt` dans Neon. Les révisions, commentaires, liens d'origine et snapshots historiques sont conservés.
- Restauration depuis « Chapitres retirés » dans la vue d’ensemble. Aucun effacement définitif fourni, même après retrait.
- RBAC serveur OWNER/EDITOR sur suppression et restauration ; CSRF, validation d'empreinte de version (date et révision), audit, contrôle de concurrence et accès cross-tenant négatif.
- Tous les éléments de navigation chapitre disposent du menu `⋯` (ouvrir, renommer, retirer selon les droits), y compris éditeur et vue d’ensemble.
- Sidebar Manuscrit indépendante scrollable avec barre discrète et centrage du chapitre sélectionné ; sur mobile (<761px), panneau latéral ouvrable et lien visible « Vue d’ensemble ».
- Menus au clic droit et `Shift+F10` sur chapitres, ouvrages, versions, commentaires, avec actions fondées sur les permissions et menus portalisés pour éviter le clipping et le débordement mobile.
- Raccourcis clavier : Ctrl/Cmd+S, Ctrl/Cmd+Shift+O, Ctrl/Cmd+Shift+K, Ctrl/Cmd+Shift+N, Alt+Shift+M, Alt+Shift+↑/↓, ?, et Escape ; documentation affichable dans l'application.
- Migration additive `20261104164000_chapter_soft_delete`, pas de modification des données existantes.

## Risques et limites

- Une suppression n'est pas une purge ; les versions historiques et exports de snapshots demeurent. Une restauration de snapshot incluant un chapitre retiré reste bloquée jusqu'à restauration explicite de ce chapitre.
- Le clic droit natif dans les champs et le texte éditable est conservé. Les raccourcis sont documentés, mais la recette humaine sur Android/iOS et sur clavier doit confirmer l'accessibilité réelle.
- Les modifications non enregistrées ne doivent pas être perdues à la navigation ; les commandes de déplacement exigent un brouillon enregistré.
- L'antivirus isolé et la sauvegarde binaire réelle ne sont toujours pas raccordés à Supabase ; #104 et #126 restent ouverts et le mode strict demeure OFF.
- **Ne pas fusionner avant E2E v0.19.0-alpha BON**. Déploiement depuis main seulement, snapshot Neon pré-prod, Preview désactivées.
