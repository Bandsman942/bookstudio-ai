# BookStudio AI by DTSC — candidate v0.11.0-alpha

**Statut : CANDIDATE NON DÉPLOYÉE.** Dernière production vérifiée : v0.10.0-alpha, commit 01bad488637244cfe60e4b9a3d32fc9c7d93cd06.

## Contenu de la version

### BS-006a : première tranche du pipeline DOCX (#7, issue #90)
- Dans les fichiers sources, les documents DOCX accessibles ont une action « Prévisualiser DOCX ».
- Après vérification des permissions, une URL privée de téléchargement valable 90 secondes est générée sur le serveur. Le navigateur récupère le fichier directement de Supabase Storage, **sans transfert binaire par Vercel ni envoi vers l'IA**.
- L'archive ZIP OOXML est contrôlée avant décompression : taille 20 Mio maximum, nombre d'entrées, noms sûrs, archives suspectes, macros/contenu actif, taux d'expansion et taille XML.
- Aperçu de lecture des paragraphes et titres, volontairement limité (200 blocs, 100 000 caractères) et accompagné d'avertissements pour tableaux, images, notes, liens externes, champs et modifications suivies.
- UI FR/EN, mobile, thèmes clair/sombre et tests synthétiques de refus.

### Limites du lot
**Ce n'est pas un import DOCX éditable.** Aucun chapitre ou texte n'est créé ni modifié depuis la prévisualisation. Les originaux restent dans Supabase Storage.

## Gates
1. CI test-and-build (pnpm docx:check, worker tests, HTTP E2E, typecheck et build).
2. Recette détaillée : docs/qa/E2E-DOCX-PRIVATE-PREVIEW.md ; contrôles de confidentialité, fichiers variés et connexions lentes.
3. **Validation propriétaire « E2E v0.11.0-alpha BON »** avant toute fusion ; previews désactivées, production depuis main uniquement.
4. Snapshot Neon et contrôles Vercel READY/santé/version après déploiement, puis journal de release.

## Risques et limites
- Analyse strictement locale et indicative : aucun antivirus, checksum du binaire, détection de contenu malveillant garantie, contrôle exhaustif de tous les formats OOXML, worker isolé, mise en page Word fidèle ou restauration éprouvée.
- Les budgets ZIP s'appuient sur les tailles déclarées par l'archive ; ils réduisent le risque sans établir une garantie contre toutes les attaques par décompression. N'utiliser que des sources de test non sensibles pour la recette.
- Les documents complexes (images, tableaux, notes, formules, styles Word avancés, révisions) nécessitent toujours une revue humaine dans un éditeur Word.
- Le stockage Supabase doit autoriser le fetch navigateur CORS sur l'origine protégée ; le vérifier avant déclaration de conformité.

## Réversibilité
Aucune migration SQL. En cas d'échec, rollback vers la v0.10.0 sans supprimer les sources Supabase.
