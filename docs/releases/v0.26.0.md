# BOOKSTUDIO AI — v0.26.0-alpha (déployée en production privée le 8 novembre 2026)

## Contenu

Sous-issue **BS-004e #145**, liée au parent P0 #5 : tableau de bord privé par ouvrage indiquant la proportion de chapitres actifs contenant du texte enregistré, les chapitres encore vides, les chapitres retirés, le nombre de lignes de révision et les snapshots. L'écran présente le chapitre le plus récemment modifié, la date de dernière sauvegarde et des liens contextualisés.

La vue d'ensemble affiche désormais un badge de présence de texte sur chaque chapitre. Les informations sont dérivées de la **dernière** révision enregistrée des chapitres actifs de l'édition courante, pas du contenu d'une version ancienne. API `GET /api/v1/books/{bookId}/progress` privée, contrôle RBAC sur le livre, réponse sans prose ni source. En cas d'échec de l'agrégation, l'auteur peut toujours ouvrir/éditer son livre.

Tests unitaires du résumé, E2E HTTP privés/cross-tenant et snapshots, UI responsive clair/sombre FR/EN. Aucune nouvelle migration Prisma ou variable Vercel.

## Risques

- **Candidat uniquement** : CI verte et validation propriétaire `E2E v0.26.0-alpha BON` requises avant snapshot/fusion/déploiement.
- La proportion mesure les chapitres qui ont du texte, **pas l'achèvement, ni la qualité, ni le nombre de mots**. Les révisions incluent la ligne initiale par chapitre ; snapshots comptés pour le livre entier ; chapitres retirés exclus du nombre de révisions de l'édition courante.
- Dernier chapitre modifié peut correspondre à un renommage et non à une frappe. Indicateurs à réactualiser après autosave ; grandes collections à tester pour les latences.
- ClamAV réel non installé, issues P0 #104/#126/#131/#133 toujours ouvertes et flags OFF. Parent BS-004 #5 maintenu ouvert pour les éditions et autres fonctions du cahier des charges.
