# BOOKSTUDIO AI — v0.27.0-alpha (candidate NON fusionnée, NON déployée)

## Contenu

Sous-issue **BS-004f #148** du parent P0 #5 : gestion de plusieurs éditions d'un ouvrage. L'auteur peut consulter un catalogue des éditions, créer une **nouvelle édition par copie** des dernières révisions enregistrées des chapitres actifs, conserver intégralement les éditions antérieures et lire les anciens chapitres en mode historique strictement non modifiable.

La création emploie une transaction Serializable + RBAC OWNER/EDITOR + CSRF + double contrôle `expectedEditionId` / `expectedUpdatedAt`, nouveaux UUID et nouvelles révisions 0, audit sans prose, statut éditorial DRAFT pour la nouvelle édition. Les anciennes révisions, commentaires et snapshots restent inchangés. Les lecteurs autorisés consultent l'histoire en texte brut, aucune mutation d'édition ancienne. UI FR/EN responsive, toasts spécifiques, tests HTTP E2E multi-tenant/conflits/snapshots.

**Aucune nouvelle migration SQL ni variable Vercel.**

## Risques

- **PR candidate uniquement** : CI et E2E propriétaire `v0.27.0-alpha BON` obligatoires avant snapshot Neon, fusion `main` et production.
- Seuls les **derniers contenus sauvegardés** sont copiés ; enregistrer les brouillons locaux avant de confirmer. Les commentaires ancrés, références de sources, verdicts de scan et états d'approbation **ne sont pas copiés**.
- Les anciennes éditions ont un **aperçu texte brut** (pas une reproduction fidèle Word pour tableaux/images/formatage) ; elles sont strictement en lecture seule dans ce lot.
- Capacité synchrone de copie : **500 chapitres actifs et 20 MiB cumulés JSON + texte**. Les livres plus volumineux réclament une solution asynchrone future. Aucun ancien contenu n'est détruit si le seuil est dépassé.
- `Book.status` revient à DRAFT à la nouvelle édition ; le statut PUBLISHED n'a jamais de publication externe automatique. La gestion des auteurs simultanés et les éditions éditables en parallèle restent hors de cette tranche.
- Aucun ClamAV dédié opérationnel : #104/#126/#131/#133 ouverts, flags antivirus et mode strict OFF. Le parent #5 reste ouvert pour les autres critères.
