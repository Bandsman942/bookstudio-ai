## Contrôles et limites

- Le test HTTP sur la production confirme l'API santé, la connexion PostgreSQL et le commit ; **cela ne constitue pas un E2E navigateur connecté à la production**. Les tests d'ACL et d'interactions ont été exécutés en CI avec PostgreSQL 18 ; la recette propriétaire a été déclarée « bon » avant publication.
- Aucun contenu privé de manuscrit, e-mail, cookie ou jeton n'a été imprimé ou consigné.
- **Import DOCX/PDF depuis l'interface encore non disponible** ; stockage privé Vercel Blob bloqué par permissions insuffisantes (issue #46) ; pas d'IA connectée, d'antivirus ni de pipeline OCR.
- L'application reste **alpha privée**, non disponibilité générale v1.0.0.
- Les variables de première activation propriétaire ont été **neutralisées** mais non supprimées physiquement via le connecteur ; les retirer dans l'interface Vercel est une action administrative séparée.
