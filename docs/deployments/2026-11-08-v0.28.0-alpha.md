## Limites et surveillance

- Comparaison conservatrice, non assimilable à un diff de prose ni une preuve absolue de filiation des chapitres ; limite de 350 chapitres actifs par édition.
- Scanner ClamAV **non installé** sur hôte dédié ; files et worker **désactivés**, mode strict `BOOKSTUDIO_REQUIRE_SCANNED_SOURCES=false`. Tickets #104/#126/#131/#133 à poursuivre ultérieurement ; ne pas présenter les manuscrits comme scannés.
- Vérifier manuellement sur le domaine réel le focus et la fermeture des menus en Chrome mobile/desktop, les comparaisons sur livres autorisés et le comportement en connexion faible. L'E2E propriétaire BON précède la fusion ; les sondes HTTP post-déploiement ne constituent pas un E2E complet de production.
- La vérification directe d'un run **CI main** distinct n'était pas accessible via l'outil de lecture GitHub disponible lors de la consignation ; ne pas l'affirmer sans pièce CI correspondante.
