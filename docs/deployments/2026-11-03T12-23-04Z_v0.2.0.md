## Fonctionnalités de cette version
Socle rédaction et bibliothèque privée ; chapitres Tiptap, révisions et sauvegarde avec conflits ; versions immuables et restauration non destructive ; export DOCX, Markdown et PDF de lecture ; limitation des abus de connexion ; activation privée propriétaire ; API version/health. Voir `CHANGELOG.md`.

## Limites et risques encore ouverts
- Première alpha privée, **pas** de version stable ni de disponibilité commerciale.
- Import DOCX/PDF via interface, OCR, antivirus, stockage objet des sources, édition PDF imprimeur, IA et bibliographie avancée **non livrés**.
- Le test E2E navigateur avec manuscrit réel doit être conduit après activation propriétaire.
- Les sauvegardes Neon sont configurées mais la restauration opérationnelle n'a pas encore été éprouvée sur une copie.
- Ne jamais ajouter de comptes arbitraires ni ouvrir les inscriptions publiques avant les contrôles de sécurité.
